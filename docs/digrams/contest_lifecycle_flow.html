Valid state transitions
UPCOMING → manual/auto start → RUNNING → manual pause → PAUSED → manual resume → RUNNING → auto/manual end → ENDED ⛔
UPCOMING → ENDED direct: allowed via manual end (juryOverride required — no effectiveEndTime for UPCOMING)
PAUSED → ENDED: always requires juryOverride (resolveEffectiveEndTime() returns null while PAUSED)
RUNNING → ENDED: auto when now ≥ effectiveEndTime; manual with juryOverride before effectiveEndTime
ENDED → anything: ❌ terminal; isValidTransition(ENDED, *) always returns false
