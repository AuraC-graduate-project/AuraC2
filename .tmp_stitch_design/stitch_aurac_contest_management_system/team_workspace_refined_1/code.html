B. Binary Tree Balancing Act

schedule Time Limit: 2.0s
memory Memory Limit: 256MB

You are given a highly unstable binary search tree containing N nodes. Each node represents a server in a distributed network, and the edges represent communication links. Due to a recent solar flare, the tree has become extremely unbalanced, leading to severe latency in querying.

Your task is to rebalance this tree such that the absolute difference in heights of the left and right subtrees for any given node is at most K. However, moving a node to a different position incurs a cost proportional to its weight W_i. Find the minimum total cost to achieve the required balance factor.

Input Format

The first line contains two integers N and K (1 ≤ N ≤ 10^5, 0 ≤ K ≤ N).
The following N lines each contain three integers: V_i (value), W_i (weight), and P_i (parent index, 0 if root).

Output Format

Print a single integer: the minimum cost to balance the tree.
