Problem Statement

The galactic federation has detected multiple alien signatures attempting to breach the core network. The network can be represented as an undirected graph with N nodes and M edges.

Each node represents a planetary defense station, and each edge is a hyperspace routing lane. The aliens will target exactly one specific routing lane to disable. Your task is to determine the maximum possible critical path length between any two defense stations after any single routing lane is destroyed.

You must output the maximum diameter of the remaining graph components for every possible edge removal scenario.
