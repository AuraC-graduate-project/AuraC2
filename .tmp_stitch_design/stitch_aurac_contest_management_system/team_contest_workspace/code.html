A. Array Balance

Time Limit: 2.0s Memory Limit: 256MB

You are given an array of n positive integers. You need to divide the array into two contiguous subsegments such that the absolute difference between the sums of the elements in the two subsegments is minimized.

Formally, you need to find an index k (1 ≤ k < n) such that the value |(a₁ + a₂ + ... + aₖ) - (aₖ₊₁ + ... + aₙ)| is as small as possible.

Input

The first line contains a single integer t (1 ≤ t ≤ 10⁴) — the number of test cases.

For each test case, the first line contains an integer n (2 ≤ n ≤ 2·10⁵) — the length of the array. The second line contains n integers a₁, a₂, ..., aₙ (1 ≤ aᵢ ≤ 10⁹).

Output

For each test case, output a single integer — the minimum possible absolute difference.

Example Input

3
5
3 1 4 1 5
2
10 10
4
1 2 3 4

Example Output

2
0
2
