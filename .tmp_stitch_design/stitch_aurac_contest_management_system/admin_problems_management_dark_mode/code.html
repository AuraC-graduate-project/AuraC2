B. Dynamic Path Optimization

timer Time Limit 2.0 seconds
memory Memory Limit 512 Megabytes
input I/O Standard STDIN/STDOUT

Problem Statement

Given a directed acyclic graph (DAG) representing a city's road network, where each node is an intersection and each edge has a traversal cost (representing time), find the optimal path from node S to node E.

However, you are allowed to negate the cost of at most K edges along your path (representing a speed boost item). Determine the minimum possible time to reach the destination.
